# Anirudh Chauhan — Portfolio

An interactive 3D globe portfolio. Each pin on the Earth is a website I built: hover a pin to preview it, click to visit.

- Drag to spin the globe, scroll or pinch to zoom
- Open **About** for my résumé and contact details

Built with HTML, CSS and JavaScript, with three.js for the 3D Earth and Moon. The whole site is a single `index.html` file.
